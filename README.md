## Elevator Pitch

**AuraTorrent** is a fast open-source WebUI for qBittorrent. Built on Vue 3 and Vite, it includes dynamic scheduling, real-time telemetry HUDs, and deep customization. It provides a highly responsive, app-like experience across all devices with deep API integration for minimal overhead.

## ✨ Features

- **Bandwidth Scheduling Matrix**: 7x24 visual heatmap grid to paint your bandwidth schedule and automatically throttle qBittorrent.
- **Global Command Palette**: Instant navigation and torrent search with `Cmd/Ctrl + K`.
- **AuraTheme Engine**: Real-time glassmorphism and neon styling with live CSS variables.
- **Global Speed Ticker HUD**: Floating I/O sparkline overlay (`Ctrl+Shift+T`).
- **Mobile Responsive (PWA)**: Installable via Chrome or Safari as a native-feeling app.
- **Telegram Companion Bot**: AuraBot integration for real-time download alerts.

## 🚀 Quick Start

1. **Download** the [latest release](https://github.com/BiosSystem/AuraTorrent/releases/latest/download/auratorrent.zip).
2. **Extract** the ZIP to your qBittorrent WebUI directory (`/path/to/qbittorrent/webui`).
3. **Enable** it in qBittorrent: Open `Options → WebUI`, check **Use alternative Web UI**, and point it to the extracted folder.
4. **Reload** your browser.

> [!NOTE]
> For Docker setups, mount the extracted folder into your container's WebUI directory or use our published image `ghcr.io/biossystem/auratorrent:latest`.
